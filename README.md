# Simular_Investimentos_no_Excel-DIO
Ferramenta prática de simulação de investimentos em fundos imobiliários, com base nos conceitos explanados de Excell através do Cursso de Excel com IA da DIO.

# DESCRIÇÃO
O projeto consiste na criação de uma ferramenta simples em Excel para simular investimentos em fundos imobiliários. A planilha permite calcular o valor total investido, o patrimônio acumulado e os dividendos mensais, ajudando o usuário a entender melhor o impacto de seus investimentos ao longo do tempo. Este modelo pode ser usado como base para futuras expansões e personalizações, oferecendo uma solução prática e acessível para investidores iniciantes.

# Objetivos de Aprendizagem Aplicados:
- Criação de ferramentas de simulação de investimentos em Excel para simular investimentos em fundos imobiliários;
- Aplicação de cálculos financeiros como rendimento mensal e cálculo de dividendos utilizando formulas e configuração de celulas;
- Documentação de processos técnicos de forma clara e estruturada através de formatação do arquivo e organição estrutural visual; 
- Utilizar o GitHub como ferramenta para compartilhamento de documentação técnica para compartilhamento da ferramenta gerada.
